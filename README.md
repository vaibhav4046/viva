# VIVA

**The AI that learns how you think.** VIVA is a voice-first learning memory: speak while you study, and each confusion becomes a Thought Mark on a Misconception Graph, linked to the exact source passage, driving the next 10-minute lesson.

Live: https://viva-vaibhav4046s-projects.vercel.app · Film: [demo-production/viva-demo.mp4](demo-production/viva-demo.mp4) (65.77 s, 1080p30, narrated, captioned) · Evidence: [FINAL_VALIDATION.md](docs/evidence/FINAL_VALIDATION.md) · Judge map: [JUDGE_EVALUATION.md](docs/evidence/JUDGE_EVALUATION.md) · Design: [DESIGN_V2.md](docs/design/DESIGN_V2.md)

> Every question. Every hesitation. Every explanation. Becomes memory.

## Try it in 90 seconds

1. **Landing** — open the live URL. Hero: **“STUDY. SPEAK. VIVA REMEMBERS.”** Click **Start a 10-minute lesson**.
2. **`/today` — the 10-minute path.** Course-scoped segments from your own history (1 misconception → 2 weak concept → 3 recall → 4 teachback → 5 summary), each with a WHY line; answer one inline recall (**Recall now**) or read the **Your week** strip.
3. **Speak a wrong idea.** Go to **`/exam` → Enter VIVA**, choose **Answer aloud** (hold **Space**, or type) and answer wrong on purpose: *“It wouldn’t know which words are important.”* VIVA flags the claim as a **MISCONCEPTION** with a hint. To capture a spoken thought instead, push-to-talk also lives on **`/demo` Study** (linked from `/today`).
4. **`/memory` — misconception replay.** Open the flagged concept → **“Show me where I went wrong”**: the per-event outcome Δ, reason, hint and the source chunk the claim resolves to.
5. **`/exam` — close the loop.** **Enter VIVA** gives claim-level feedback (correct / missing / misconception / next) and an adaptive next question; switch to **Teach VIVA** to explain it back and be scored.

No account needed (isolated demo cookie); voice or typed everywhere; the mic path returns an honest 503 without a key and nothing is faked.

## Honest limits (irreducible, per JUDGE_EVALUATION.md)

- **Manual NVDA/screen-reader pass** — a human procedure; automation (axe 8/8, keyboard, live-region) cannot certify a screen reader.
- **Free-tier art composition** — one anonymous model, fixed 1024×576, abstract rather than literal manifest compositions.
- **Retention history** — the engine is live and projects 7 days; real history only accrues over real days.

## What it does

| | |
|---|---|
| **Compiles speech into learning events** | AssemblyAI transcript → intent + concepts + importance → append-only `LearningEvent`. Cleanup never drops negation, numbers or names. |
| **Grounds every claim in the source** | Lexical + concept retrieval over 12 citable chunks; verifier repairs sourceless citations. Insufficient evidence is stated, not invented. |
| **Derives mastery, never guesses it** | Pure reducer fold: confusion −0.08, wrong claim −0.12, correct teachback +0.12. Every delta ships a reason; displayed as *VIVA estimate*. |
| **Teaches socratically** | Smallest useful hint first; exam questions get guided reasoning, never an answer dump; jargon gate on “explain simply”. |
| **Examines aloud** | VIVA Exam: claim-level feedback (correct / missing / misconception / next), adaptive next question, honestly labelled *practice assessment*. |
| **Survives failure** | No key → honest 503 + typed fallback. Unrecognized speech still lands as a labelled `note` event (deterministic compiler, `src/lib/compiler.ts`). No speech → no junk event. |

Recorded golden path ([demo/canonical-run.json](demo/canonical-run.json)): one confusion moves positional mastery 0.44 → 0.36 with reason; one wrong spoken belief is flagged (0.36 → 0.24); one correction recovers it (→ 0.30) — computed by the real reducer, cited to real chunks.

## Quick install

```bash
git clone https://github.com/vaibhav4046/viva && cd viva
npm install
cp .env.example .env.local   # add ASSEMBLYAI_API_KEY for live voice
npm run dev                  # http://localhost:3000  (demo path: /demo)
```

Voice without a key: the mic path returns 503 and the UI offers typing — nothing is faked. With a key: real mic → real AssemblyAI (`speech_models` `["universal-3-5-pro","universal-2"]`, course keyterms, language detection).
